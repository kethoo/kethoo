I'm a backend and ML engineer at [Quissly](https://quissly.com) in Tbilisi. I work on product search (hybrid BM25 + vector retrieval on Qdrant) and multi-agent LLM chat for e-commerce. Outside work I build hardware instruments and Claude Code plugins.

## Projects

| | |
|---|---|
| **[mimu-gloves](https://github.com/kethoo/mimu-gloves)** | Gloves you play like an instrument: an ESP32 and a BNO08x motion sensor on each hand stream over Bluetooth LE to a real-time synthesizer written in Python and NumPy. |
